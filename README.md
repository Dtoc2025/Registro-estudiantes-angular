##  Descripción del Problema
Una institución educativa necesita digitalizar el registro de sus estudiantes. 
La aplicación debe validar la información antes de almacenarla y permitir 
administrar los registros creados.

##  Instalación y Configuración

### Prerrequisitos
- Node.js (versión 18 o superior)
- pnpm (o npm)

### Pasos para ejecutar el proyecto
```bash
# Clonar el repositorio
git clone https://github.com/Dtoc2025/Registro-estudiantes-angular.git
cd Registro-estudiantes-angular

# Cambiar a la rama developer
git checkout developer

# Instalar dependencias
pnpm install

# Ejecutar el proyecto
pnpm ng serve -o
